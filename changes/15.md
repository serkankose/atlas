- **A quoted `|`, `&`, `;` or `$` in a Bash command no longer crashes the hook.** `grep 'a|b' f` aborted
  `atlas --hook` with a stack overflow (exit 134), so Claude Code showed "PreToolUse:Bash hook failed" on every
  such command and the rewrite was lost. The command now routes like any other read.
